# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/raci-sh/homebrew-tap/security/advisories/new).
Do not open a public issue.

In scope: cask integrity (URLs, checksums), install/uninstall hooks, and the workflows in
this repository. Vulnerabilities in the `raci` CLI itself belong in
[raci-CLI](https://github.com/raci-sh/raci-CLI/security/advisories/new).

We aim to acknowledge reports within a few working days.
