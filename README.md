[Homebrew](https://brew.sh) tap for [RACI.sh](https://raci.sh) tools.

## Available casks

| Cask | Description | Source |
|------|-------------|--------|
| `raci` | RACI.sh CLI: who is Responsible, Accountable, Consulted and Informed, per realm, offline from your repository | [raci-CLI](https://github.com/raci-sh/raci-CLI) |

## Install

```bash
brew tap raci-sh/tap
brew trust --cask raci-sh/tap/raci
brew install --cask raci
```

Recent Homebrew versions refuse to load casks from untrusted taps
(`Refusing to load cask raci-sh/tap/raci from untrusted tap`), so the `brew trust` step is
required once. It trusts only the `raci` cask; `brew trust raci-sh/tap` trusts the whole tap,
including future casks. See [Tap Trust](https://docs.brew.sh/Tap-Trust).

Upgrade and uninstall:

```bash
brew upgrade --cask raci
brew uninstall --cask raci
```

### Notes

- **macOS only.** On Linux, download the tarball from the
  [raci-CLI releases](https://github.com/raci-sh/raci-CLI/releases).
- **Unsigned binaries.** `raci` is not code-signed. If macOS reports it as damaged or blocks it, run:

  ```bash
  xattr -dr com.apple.quarantine "$(brew --prefix)/bin/raci"
  ```

## How it is maintained

Casks in `Casks/` are generated by GoReleaser from
[raci-CLI](https://github.com/raci-sh/raci-CLI) on each release. Do not edit them by hand;
change the `homebrew_casks` section of that repo's `.goreleaser.yml` instead.

Tap releases (workflow and tooling changes) follow [Semantic Versioning](https://semver.org)
via [release-please](https://github.com/googleapis/release-please), independent of the `raci`
version in the cask.
